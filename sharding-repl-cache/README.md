# Задание 4

## Как запустить

Запускаем MongoDB, Redis и приложение

```shell
docker compose up -d
```

Конфигурируем шардирование и репликацию, заполняем MongoDB данными

(при появлении сообщения "Waiting for ..." необходимо подождать, пока все реплики будут готовы)

```shell
./scripts/mongo-init.sh
```

Вывести общее количество документов в коллекции и отдельно на каждой реплике каждого шарда

```shell
./scripts/mongo-count.sh
```

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080

## Доступные эндпоинты

Список доступных эндпоинтов, swagger http://<ip виртуальной машины>:8080/docs
